Entry for the [The Houseplant Out-of-Office](https://make.fun/competitions/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047) bounty on make.fun.

`main.ts` writes one original out-of-office auto-reply, as if a houseplant sent it (112 characters, one line), to `/output/entry.txt`. Offline and deterministic — no network, no API calls.

> Out of office — I'm the fern by the copier. Last watered in March. Your email will be ignored in order received.
